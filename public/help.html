Set up a local server

This app reads Claude Code / Codex usage from a local server on your Mac or PC. Auth tokens stay on that machine — only usage (%) and reset times are sent to the glasses.

Steps

  1. Make sure your Mac/PC has Bun or Node 18+ (Bun recommended) curl -fsSL https://bun.sh/install | bash
  2. Start the local server (serves the API on port 8723) bunx eveng2-toolbar server npx eveng2-toolbar server
  3. Read the LAN address it prints on startup. It looks like http://192.168.x.x:8723 (the server logs your machine's LAN IP).
  4. Enter that http://<LAN-IP>:8723 as the URL in the server settings, then tap Test

Connect to the same Wi-Fi. It won't connect if your Mac/PC and phone (glasses) are on different networks.

Updates only while the server is running. It stops when the machine sleeps.
