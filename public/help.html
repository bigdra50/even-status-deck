ローカルサーバーの設定方法

このアプリは Mac 上で動くローカルサーバーから Claude Code / Codex の使用状況を読み取ります。 認証トークンは Mac の中だけで使われ、グラスには使用率（%）と reset 時刻しか送られません。

手順

  1. Mac にリポジトリを用意する ghq get bigdra50/eveng2-toolbar
  2. 依存をインストールする bun install
  3. dev server を起動する（このサーバーが API も同一オリジンで配信します） bun run dev
  4. Mac の LAN IP を確認する ipconfig getifaddr en0
  5. Machine 設定の「接続先」に http://<LAN-IP>:5173 を入力し、「接続テスト」を押す

QR ショートカット

手入力の代わりに、Mac で次を実行すると接続先 URL の QR コードが表示され、スマホから読み取れます。

bun run qr

同じ Wi-Fi に接続してください。 Mac とスマホ（グラス）が別ネットワークだと接続できません。

dev server を起動している間だけ表示が更新されます。Mac をスリープすると停止します。
