Set up a local server

Time, date, and glasses battery work without a server. A local server is optional — it adds your Mac/PC system info and Claude Code / Codex usage. Auth tokens stay on that machine — only usage (%) and reset times are sent to the glasses.

Steps

  1. Make sure your Mac/PC has Bun or Node 18+ (Bun recommended) curl -fsSL https://bun.sh/install | bash
  2. Start the local server (serves the API on port 8723) bunx even-status-deck server npx even-status-deck server
  3. Read the LAN address it prints on startup. It looks like http://192.168.x.x:8723 (the server logs your machine's LAN IP).
  4. Enter that http://<LAN-IP>:8723 as the URL in the server settings, then tap Test

Connect to the same Wi-Fi. It won't connect if your Mac/PC and phone (glasses) are on different networks.

Updates only while the server is running. It stops when the machine sleeps.

Troubleshooting

Glasses go blank after a few minutes in the foreground. Known issue caused by the iOS WebView being reclaimed by the system. Reopen this companion to recover.

Forwarding Mac notifications? The watcher needs Full Disk Access (System Settings > Privacy & Security > Full Disk Access).

Conditional display

Any metric can be shown only when a condition holds, or surfaced as a pop-up instead of sitting in a row. Open a metric's Show row to set this up.

  1. Under a metric, in the Show row, tap Add condition and pick one: a threshold (e.g. level ≤ 20%, optionally on another metric in the same group), On update (after a value changes), Has value, or At place (a saved location). Two or more conditions combine with All of / Any of.
  2. Choose how to Present it: Inline keeps the metric in its row (shown only while the condition holds); Toast pops a one-line message at the bottom; Notification pops a centered card.
  3. For Toast / Notification, set the auto-hide seconds (default 5s) and, optionally, a custom message (otherwise it shows label value, e.g. Battery 18%).

Example — low-battery alert. On the Estimated time left metric, add level ≤ 20% and set Present to Toast, 5s, text Battery low. A toast appears the moment the battery drops to 20%.

How pop-ups behave. Toast / Notification fire once at the moment the condition becomes true (not while it is already true), at most once per 30s per metric, and auto-hide after the seconds you set. Inline simply shows or hides the row. Conditions and Present are shared across all presets.
